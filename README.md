# Team Version Control Project

## Project Title
Online Book Store

## Project Description
This project demonstrates Git and GitHub version control for a team project.

## Git Workflow
1. The main branch contains the stable project.
2. Each team member works on a separate branch.
3. Changes are committed regularly.
4. Branches are pushed to GitHub.
5. Pull requests are created for code review.
6. Approved pull requests are merged into the main branch.
7. Merge conflicts are resolved when necessary.

## Branches
- main - Stable project version
- frontend - Frontend module
- styling - Styling module
- conflict-demo - Conflict resolution demonstration

## Tools Used
- Git
- GitHub
- Visual Studio Code

## Conclusion
This project demonstrates repository creation, branching, commits, pull requests, code review, merging, conflict resolution, and documentation.
